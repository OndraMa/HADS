## Původní popis PR

Nahlášený incident nyní může v instalovatelné samostatné aplikaci spustit původní NousResearch Hermes: vybere povolená skutečná čtení, získá další důkazy, předá práci logické specializaci a uloží citovaný český závěr nebo nezávisle validovaný návrh dalšího postupu. Předchozí instalační aplikace tento runtime neobsahovala.

Čtecí broker, controller, původní worker a stávající opravný plánovač mají oddělené odpovědnosti. AI nemá HA/model credentials, sockety, obecný shell/Python/MCP proxy ani produkční write cestu. Vlastník se ověřuje přes Core; model a veřejný výzkum vyžadují oddělený souhlas. Trvalá fronta, rozpočty, deduplikace, skutečný SIGKILL/restart, chybějící zdroje a paměťová brána nesmějí vytvořit falešný úspěch nebo tiché placené opakování.

Katalog zahrnuje nativní Core/registry/traces/historii/Action history/Repairs/System Health, Supervisor kontrakty, trvalý ZHA žurnál a volitelné přesně omezené MA FastMCP čtení. Devět logických rolí běží postupně v jediném originálním Hermes workeru. Návrh reference se validuje proti čerstvým důkazům a předává původnímu opravné­mu základu pouze v laboratoři; produkční UI nabízí ruční postup nebo zamítnutí, nikoli falešné schválení nepodporovaného zápisu.

**Ověření:** [GitHub Actions 42678100603](https://github.com/OndraMa/HADS/actions/runs/42678100603), skutečný nativní AMD64 i ARM64, obě větve success. Každá provedla 150 offline regresí, skutečný Core 2026.11.0 + původní připnutý Hermes, osm požadavků na skriptovaný HTTPS model, role/citace/návrh, restart a negativní nástroje. Samostatný výchozí instalační image bez Core lab načetl skutečný agent bez modelu při 768 MiB, správně odmítl 512 MiB, vynutil UID/capabilities a uchoval incident po restartu. Instalační posloupnost má výslovně náhradní HA CLI. Chromium průchod s náhradním ingressem ověřil první nastavení, hlášení a trvalou volbu ručního postupu.

**Dodání:** [KE_STAZENI/HADS_Next_0.2.0-dev1](https://github.com/OndraMa/HADS/tree/codex/hads-next-investigation/KE_STAZENI/HADS_Next_0.2.0-dev1) — přesně testovaný instalátor, český návod, SHA-256, protokoly a kompletní ZIP se zdroji. Instalátor má SHA-256 `ea0c569b03f669d54f2ba5f709821601aad3b45236122c392c86bfe0a09fcb9c`; obě architektury vytvořily stejné bajty. Všech 34 payload souborů odpovídá zdrojovému commitu `7b3df242cd3aa056d76d64a478f122dca4fed6e9`; pozdější commity doplňují dokumentaci/balení, runtime zdroje nemění. ZIP obsahuje 207 souborů s ověřenými hashi. Staré vydané archivy, RC3 a main zůstávají zachované; nový slug je `local_hads_next_investigation`.

Autonomní úsudek LLM, skutečný Supervisor/MA, fyzické rádio/Zigbee, RPi 4 / 2 GB, skutečný HAOS ingress/AppArmor, OneDrive restore a produkční schvalované zápisy zůstávají čekající. Kontejnerový ARM64 úspěch není RPi ani HAOS přejímka. Apt repozitáře nejsou zmrazený snapshot; Python constraints, Hermes pin, base index a přesné testované image jsou zaznamenané.
