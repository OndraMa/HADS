## Původní popis PR

Watchman `unavail` was left unclassified, missing entities disappeared from the selector, and source outages were counted as household functional faults. RC7 normalizes the upstream format, follows concrete targets through registry/state/history and passive ZHA/Toolkit cache, preserves unavailable targets and recurrence, and separates diagnostic history from functional cases and actual user decisions.

The Toolkit adapter accepts only a fixed `zha_devices` cache response with selected fields. No RF scan, file export, arbitrary service arguments, network keys, Zigbee writes or additional AI permissions. Hermes can request only case-linked, current, evidence-matched target diagnosis. Collection remains bounded and continues without AI and after evidence storage limits.
