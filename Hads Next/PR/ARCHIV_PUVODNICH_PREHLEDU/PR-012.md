## Původní popis PR

Uživatelovo běžící RC3 ukázalo nález Marketplace/github_web bez důvodu a paměť 373 MiB při bráně 576 MiB. Detail vracel obecný závěr, prázdné další důkazy a nesouvisející světelnou opravu; obě diagnostické informace se počítaly jako funkční problémy domácnosti.

Změna dává diagnostice vlastní viditelnou sekci, konkrétní český závěr a opakované podporované nativní čtení bez AI. Uchovává bezpečně vybrané chybové kódy a první paměťové měření bez nových výskytů z běžného kolísání. Z již načítaného System Log automaticky dohledává čerstvé záznamy příslušné integrace; ukládá čas a vybrané typy výjimek, nikdy volný text, URL, hlavičky nebo libovolný podlogger. Vodítko se nevydává za příčinu. Neúplný stream nezruší dřívější neúspěšnou kontrolu. Světelné opravy se nabízejí jen odpovídajícím automatizacím; vlastní virtuální reference má zachovanou podporu obou katalogových komponent.

Zachována paměťová ochrana 576 MiB, izolace, schvalování, evidence a všechny vydané archivy. Žádné nové endpointy nebo dodatečné síťové sondy, restart, změna DNS či placené modelové volání. Nainstalované RC3 tato zdrojová větev automaticky nemění; nový instalační balíček se nevydává. Příčina Marketplace, spotřebitel paměti a živý Hermes zůstávají neověřené.
