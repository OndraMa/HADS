## Původní popis PR

HAOS aplikace nyní ověřuje admin identitu přes Core WebSocket, trvale registruje vlastníka bez ručního ID v YAML a čte konkrétní Supervisor aplikace, statistiky a logy. Historický incident rádia načte relevantní Core historii a kontextově svázané akce; průběh kontrol i výsledek jsou česky.

Přidaná odpojená laboratoř spouští skutečný Home Assistant Core 2026.11.0. Virtuální automatizace s chybným odkazem nejprve selže. Stávající schvalovací a vykonávací modul poté po simulovaném místním souhlasu provede jedinou změnu přes skutečné config API. Skutečné spuštění, změna cíle se společným kontextem a aktivní dvousekundové sledování vytvoří český report a uzavřou spis. Řízeně vložená změna cíle znovu otevře tentýž případ.

Ověření: 101 unit/integračních regresních testů; čistý AMD64 Core container s reálnou autentizací, registry, automation trace, validací a vykonáním služby. Negativní zkoušky odmítají zápis bez souhlasu, cizí principal, nevirtuální cíl, replay a podvržený úspěšný report. Přesný image, závislosti a hashe vstupů jsou v hads-next/docs/evidence/core-lab.json; reprodukce v hads-next/lab/README_CS.md.

Tento draft není dokončený HADS ani nové vydání. Core laboratorní běh neobsahuje Hermes; jeho produkční izolovaný broker, MA FastMCP a ZHA workflow zůstávají nedokončené. Zapisovač z lab/ není součástí HAOS payloadu. Core config API nemá CAS/ETag a může měnit další položky celého YAML souboru, proto provozní zápis zůstává vypnutý. Testovací HAOS není dostupný; Supervisor/Ingress, fyzické výsledky, OneDrive restore, ARM64/RPi a živá HAOS přejímka čekají. RC3, main a vydané balíčky nejsou změněné.
