Na stránce souboru použij ikonu **Download raw file**. Nepoužívej „Uložit
stránku jako“, které by místo souboru mohlo uložit HTML GitHub stránky.
Instalátor `.sh` nespouštěj ve Windows; přenes jej do testovacího HAOS podle návodu.

**Vývojová verze / Pre-release.** Hermes a živé opravy v této instalační
aplikaci nejsou aktivní. Živý HAOS a ARM64/RPi nejsou ověřené. Historická
4.6.3 na větvi `main` není tento balíček a nepřepisuje se.

Celý ZIP byl vytvořen z commitu `b1849199ea4013d4ee20fad9cdbcbc180c8fc97b`.
Instalační soubor je bajtově shodný s dříve otestovaným `0.1.0-dev1`.
